# Web Animation Recipes Skill

> בוחרים איפה באתר ואיזו הנפשה, והסקיל בונה אותה. 30 מתכונים מוכנים לקלוד קוד.

Built by [Guy Cohen](https://www.linkedin.com/in/guycohen-ai/), AI consultant, Israel.

## מה זה עושה

כותבים לקלוד קוד "תוסיף הנפשה לאתר", והסקיל מנהל את התהליך במקום שהמודל יבחר לבד:

1. שואל איפה באתר לשים את ההנפשה, מתוך 8 מקומות. אם כבר כתבת את המקום בבקשה, הוא מדלג על השאלה.
2. מציג רק את ההנפשות שמתאימות למקום הזה, עם משפט שמתאר מה רואים ורמת מורכבות.
3. שואל שלוש שאלות לפני שהוא כותב שורת קוד: על מה האתר בנוי, מה התוכן, והאם צריך לתמוך בכל הדפדפנים ובמובייל.
4. בונה את ההנפשה מאפס לפי המתכון, והפרמטרים לכיוונון (מהירות, צבעים, כמות חלקיקים, עומק) יושבים בראש הקובץ או בפאנל קטן.
5. בודק לפני מסירה: prefers-reduced-motion, ביצועים, מגע במובייל ונגישות. ואם לא הריץ בדפדפן, הוא אומר את זה.

## 8 המקומות

| מקום | הנפשות לבחירה |
|---|---|
| Hero של דף נחיתה | שרטוט שמצייר את עצמו, רסיסי זכוכית, דף שמתנפץ לטרמינל, מנורה תלויה, סבך ג'ונגל, גפנים שגדלים, דף השקה עם אסטרונאוט |
| גלילה ומעברים | דף שמתפוגג לעשן, דף שנפתח לעולם תלת ממדי, טבעת מוביוס, דף שמתרכב מחלקיקים, ענן חלקיקים שהופך למסך טלפון, שקופיות דרך שער זוהר |
| כרטיסים ופיצ'רים | כרטיסים עם עותקים זוהרים, כרטיסי נקודות, קוביות מתגלגלות, כרטיס עם כדור נקודות, דף נקודות שנחשף בריחוף, סרטים מתפתלים |
| טפסים וקלט | טופס שקופץ לתלת ממד, קוד חד פעמי שנשרף, כפתור הקלטה מזכוכית נוזלית |
| כפתורים ומתגים | מתג כהה ובהיר מזכוכית, מחוון התקדמות נוזלי, כפתור הקלטה |
| ניווט ותפריטים | תפריט רדיאלי כמו במשחקים, סמן שהופך לתפריט, סרגל צד שנחשף כמו נייר |
| הצגת מוצר | טלפון עם מסכים שנסרקים לתוכו, חלקיקים שמתגבשים למסך, קוביות עם כרטיסי מוצר, שקופיות דרך שער זוהר |
| אפקט שמלווה את הסמן | יצור ימי ששוחה בדף, שער שחושף ממשק, ג'ונגל שנפתח, גפנים שנמשכים לסמן |

חלק מההנפשות מתאימות ליותר ממקום אחד, ולכן הן מופיעות בטבלה פעמיים.

## רמות מורכבות

| רמה | כמה | מה זה אומר |
|---|---|---|
| נמוך | 2 | HTML ו-CSS בלבד |
| בינוני | 3 | Canvas 2D |
| גבוה | 15 | WebGL, Three.js או שיידרים |
| ניסיוני | 10 | נשען על HTML-in-Canvas, שזמין היום רק ב-Chrome |

בהנפשות הניסיוניות הסקיל מנחה לבנות חלופה לשאר הדפדפנים, כמו צילום של ה-HTML כטקסטורה או גרסת CSS, ולבדוק תמיכה בזמן ריצה. החלופה לא תמיד משחזרת את כל האפקט.

## למה זה דרוש

כשמבקשים "תוסיף הנפשה" בלי הקשר, המודל בוחר לבד מה לבנות ומתחיל לכתוב קוד בלי לשאול על מובייל, על דפדפנים או על התוכן. הסקיל הופך את זה לשיחה קצרה, ורק אחרי שבחרת מקום והנפשה הוא בונה.

## התקנה ידנית ל-Claude Code

```bash
# תיקיית הסקיל
mkdir -p ~/.claude/skills/web-animation-recipes

# שלושת הקבצים. אם הורדה נכשלת, הפקודה עוצרת ומחזירה כישלון
(
for f in SKILL placements recipes; do
  curl -fsS -o ~/.claude/skills/web-animation-recipes/$f.md \
    https://raw.githubusercontent.com/guycoful/web-animation-recipes-skill/main/skills/web-animation-recipes/$f.md \
    || { echo "ההורדה של $f נכשלה. קבצים שכבר ירדו נשארים בתיקייה, תריץ שוב."; exit 1; }
done
)
```

או להוריד את שלושת הקבצים מ-`skills/web-animation-recipes/` ולשים אותם ב:
- Windows: `C:\Users\<your-user>\.claude\skills\web-animation-recipes\`
- macOS/Linux: `~/.claude/skills/web-animation-recipes/`

אחרי שהקבצים במקום, פותחים שיחה חדשה ב-Claude Code.
