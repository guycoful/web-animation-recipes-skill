# מפת מיקומים: איפה מיישמים, ואילו הנפשות מתאימות

הסוכן מציג למשתמש את רשימת המיקומים, ואחרי הבחירה רק את האפשרויות של אותו מיקום.


## hero: אזור הפתיחה (Hero) של דף נחיתה

1. Lathe Blueprint (lathe-blueprint): Hero של חברת חומרה: שרטוט טכני שמצייר את עצמו וחושף את המוצר האמיתי. מורכבות: גבוה (WebGL/Three.js/שיידרים).
2. Glass Hero (glass-hero): Hero מאחורי רסיסי זכוכית אמיתיים ששוברים את האור לצבעים. מורכבות: ניסיוני (Chrome בלבד).
3. Code Slice Hero (code-slice-hero): דף נחיתה שמתנפץ לאריחים וחושף מתחתיו טרמינל חי. מורכבות: ניסיוני (Chrome בלבד).
4. Pendant Lamp (pendant-lamp): מנורה תלויה שמאירה דף כהה, ואפשר לתפוס ולזרוק אותה. מורכבות: ניסיוני (Chrome בלבד).
5. Jungle Cursor Canopy (jungle-cursor-canopy): סבך ג'ונגל צפוף שנפתח סביב הסמן ואז מתרומם. מורכבות: גבוה (WebGL/Three.js/שיידרים).
6. Vine Overgrowth (vine-overgrowth): גפנים חיים שגדלים על דף נחיתה בתנועה ונמשכים לסמן. מורכבות: גבוה (WebGL/Three.js/שיידרים).
7. Aphelion (aphelion): דף השקה מלא: אסטרונאוט נופל ליד כוכב לכת מוסתר בזמן הגלילה. מורכבות: גבוה (WebGL/Three.js/שיידרים).

## scroll: מעבר בגלילה או מעבר בין מסכים

1. Surface Dissolve (surface-dissolve): דף נחיתה שמתקפל כמו נייר ומתפוגג לעשן בגלילה. מורכבות: ניסיוני (Chrome בלבד).
2. Viewport Transition (viewport-transition): דף שיווקי שטוח שנפתח לעולם תלת ממדי של קווים זוהרים. מורכבות: גבוה (WebGL/Three.js/שיידרים).
3. Mobius Strip (mobius-strip): דף נחיתה שעטוף על טבעת מוביוס, וגוללים כדי לנוע לאורכה. מורכבות: ניסיוני (Chrome בלבד).
4. Shader Cards (shader-cards): דף נחיתה שמתרכב מחלקיקים מעופפים בזמן הגלילה. מורכבות: ניסיוני (Chrome בלבד).
5. Particle Phones (particle-phones): ענן חלקיקים שמתגבש לכל מסך טלפון חדש בזמן הגלילה. מורכבות: בינוני (Canvas 2D).
6. Shader Deck (shader-deck): שקופיות שמסתובבות דרך שער זוהר בזמן הגלילה. מורכבות: ניסיוני (Chrome בלבד).

## cards: כרטיסים ורשת פיצ'רים

1. Trace Cards (trace-cards): כרטיסים שנוטים לכיוון הסמן ומשאירים אחריהם עותקים זוהרים. מורכבות: גבוה (WebGL/Three.js/שיידרים).
2. Pattern Cards (pattern-cards): שלושה כרטיסי פיצ'רים בולטים עם איור נקודות. מורכבות: נמוך (CSS/HTML).
3. Cuboid Chain (cuboid-chain): שורת קוביות תלת ממדיות שמתגלגלות בגל, ועל כל פאה כרטיס מוצר. מורכבות: גבוה (WebGL/Three.js/שיידרים).
4. Dot Sphere Card (dot-sphere-card): כרטיס מדע בדיוני עם כדור נקודות שמסתובב אחרי הסמן. מורכבות: גבוה (WebGL/Three.js/שיידרים).
5. Dot Hover Cards (dot-hover-cards): דף שמצויר כולו בנקודות: ריחוף מאיר כרטיס, ולחיצה מביאה אותו לפוקוס. מורכבות: בינוני (Canvas 2D).
6. Twisting Ribbons (twisting-ribbons): שורת סרטים צרים שמתפתלים ברצף ויוצרים צורות ברווחים ביניהם. מורכבות: גבוה (WebGL/Three.js/שיידרים).

## forms: טפסים, שדות קלט וקוד חד-פעמי

1. Dot Form (dot-form): טופס שקופץ לתלת ממד בלחיצה, והאותיות עולות משדה של נקודות. מורכבות: ניסיוני (Chrome בלבד).
2. One Time Code (one-time-code): כרטיס עם קוד הפעלה שנשרף אחרי שראו אותו. מורכבות: גבוה (WebGL/Three.js/שיידרים).
3. Liquid Glass Recorder (liquid-glass-recorder): כפתור הקלטה קולית מזכוכית נוזלית שנמשך לסמן וזוהר כשמדברים. מורכבות: גבוה (WebGL/Three.js/שיידרים).

## controls: כפתורים, מתגים ומחווני התקדמות

1. Glass Light Toggle (glass-light-toggle): מתג מצב כהה ובהיר עם ידית זכוכית ופס אור שמסתובב סביבה. מורכבות: גבוה (WebGL/Three.js/שיידרים).
2. Liquid Tags (liquid-tags): מחוון התקדמות מזכוכית, שהשלבים בו נמשכים זה לזה ומתמזגים כמו נוזל. מורכבות: גבוה (WebGL/Three.js/שיידרים).
3. Liquid Glass Recorder (liquid-glass-recorder): כפתור הקלטה קולית מזכוכית נוזלית שנמשך לסמן וזוהר כשמדברים. מורכבות: גבוה (WebGL/Three.js/שיידרים).

## nav: ניווט ותפריטים

1. Action Wheel (action-wheel): תפריט רדיאלי כמו במשחקים: לוחצים ומחזיקים, מכוונים לפעולה ומשחררים. מורכבות: גבוה (WebGL/Three.js/שיידרים).
2. Cursor Nav (cursor-nav): לחיצה הופכת את הסמן לתפריט תלת ממדי שמנווטים בו בתנועה למעלה ולמטה. מורכבות: נמוך (CSS/HTML).
3. Curtain Sidebar (curtain-sidebar): מקלפים את הדף מהקצה השמאלי כמו נייר כדי לחשוף את סרגל הצד. מורכבות: ניסיוני (Chrome בלבד).

1. Dot Phone Carousel (dot-phone-carousel): מסכים מחליקים מאחורי טלפון ונסרקים לתוכו בדפדוף. מורכבות: בינוני (Canvas 2D).
